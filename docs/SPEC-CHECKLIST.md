# SPEC.md checklist (Simulator proof)

Status key: **Done** = implemented and shown by a Simulator screenshot or a passing unit test in the
`keepwell-proof` artifact of `.github/workflows/sim-proof.yml`. **Partial** = implemented, but only part
of it is provable here. **Not verifiable in Simulator** = implemented, but the proof needs a device,
an Apple account, or something the Simulator cannot do.

Screenshots are `proof/screens/NN-<hook>.png` (1320x2868, iPhone 17 Pro Max). Each one is paired with
`proof/state/NN-<hook>.json`, written by the DEBUG app (`Keepwell/App/DebugState.swift`) and checked by
`scripts/sim/state-check.py`. The job fails unless Photos access is authorized, the library is non-empty and
the hook reached its screen with content: months listed, On this day items, screenshots, duplicate groups,
tray items, summary bytes, or the sheet shown. Tests are in `KeepwellTests/KeepwellTests.swift`; their result
is in `proof/test.log`. Photos access is granted by `scripts/sim/grant-photos.sh` and proven by a launch that
reads the authorization status back (`proof/diag/grant-photos.log`).

## Partial or not verifiable, in short
- **Real deletion (4, 11, 19):** the job never deletes, so the iOS confirmation, the growing space-freed total and the 50-a-day cap rest on code and tests. The `freed` hook renders the real summary screen without deleting.
- **Vision vs. fallback (5):** the duplicates screenshot proves grouping, but on the iOS 26.5 Simulator Vision cannot tell photos apart (two unrelated photos measured 0.0018), so the scan there groups by the dHash fallback. Vision's grouping quality needs a real device.
- **Limited and denied access (17, 18):** the job grants full access once; the limited banner, the picker and the denied screen are not captured.
- **StoreKit (22, 31):** `simctl launch` cannot load the local StoreKit configuration, so prices are the DEBUG stand-ins and purchase or restore cannot run.
- **Network silence (13):** shown by code inspection, not by traffic capture.
- **Store metadata (37):** outside the repo.

## Simulator setup notes
- `simctl privacy grant photos` alone is not enough on the iOS 26 runtime. It writes a TCC row with `auth_version` 1, while PhotoKit's read/write status query asks for version 2, so the app still reads "not determined". The grant script bumps the row to version 2, reboots the device and proves the result by launching the app.
- The generated library (`scripts/sim/gen-media.swift`) dates photos relative to the run day, so "On this day" and the newest month are always populated. `proof/media-manifest.tsv` lists every file and its date.
